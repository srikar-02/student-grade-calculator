# Student Grade Calculator

A simple and beginner-friendly Student Grade Calculator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Enter student name
- Add any number of subjects
- Enter marks for each subject
- Calculate total marks
- Calculate percentage
- Automatically calculate grade
- Display Pass/Fail status
- Reset the form
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
